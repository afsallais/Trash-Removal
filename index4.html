⚙️ Settings

Household members

Add, rename, reorder or remove people. The order here is the trash rotation order.

Trash rotation

One person each week, in the order set under People. Each duty week runs Monday to Sunday.

First due date

The Sunday on which the first person in the list is due.

Cleaning interval

How long each group is responsible before the next group takes over.

First due date

The Sunday on which the first group's cleaning period ends.

Groups

Groups of 2 work best. Each person can be in one group. Groups take turns in the order shown.

Sharing

Everything in Settings (people, groups, intervals, due dates) and completion status is saved to Firebase and shared with the whole household. “Reset local view” only clears which person this device has selected.

ⓘ Add a trash reminder

🍎 iPhone — Apple Calendar

  1. Choose your name in Phone reminder.
  2. Tap Add to iPhone Calendar.
  3. iPhone opens the calendar event. Tap Add.
  4. The duty repeats every 7 weeks on your Sunday.

🤖 Android — Google Calendar

  1. Choose your name in Phone reminder.
  2. Tap Add to Android Calendar.
  3. Google Calendar opens with the Sunday trash duty.
  4. Tap Save. The event repeats every 7 weeks.
Tip: The website shows the shared household rotation. The calendar reminder is a separate phone reminder, so changing the website rotation does not automatically change an already-created phone event.
